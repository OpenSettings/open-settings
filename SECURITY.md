# 🔒 Security Policy

## ✅ Supported Versions

To see which versions of OpenSettings are currently supported, please visit our [NuGet page](https://www.nuget.org/packages/OpenSettings.AspNetCore#versions-body-tab).

## 🛡 Reporting a Vulnerability

Contact us directly at [security@opensettings.net](mailto:security@opensettings.net).

We take all security concerns seriously and will respond as quickly as possible. Thank you for helping keep OpenSettings safe and secure!
